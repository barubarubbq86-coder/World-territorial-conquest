# 国盗りワールド 世界大戦版 v7

Androidの縦画面とPCで動くブラウザゲームです。`index.html` に地図データとゲーム本体を同梱しているため、ネット接続なしでも開けます。

## プレイ方法

1. `index.html` をブラウザで開き、対戦相手を「国」「大陸」「全世界」から選びます。
2. 「建国する」から名前・兵士・経済力・色を決め、地図上を指で囲んで建国します。
3. 地域をタップして詳細を表示し、侵攻します。自国の★または「自国を選択」で国力を編集できます。
4. 地図は指1本で移動、2本指で拡大縮小できます。PCではマウスホイールも使えます。
5. 全地域を併合すると勝利。自国の兵士が0になると滅亡です。「↻」で再開できます。

## GitHub Pages

このZIPを展開し、`index.html` と `README.md` をリポジトリのルートへ配置します。GitHubの Settings → Pages でデプロイ元を `main` ブランチの `/ (root)` に設定してください。単純な静的HTMLなのでビルドは不要です。

## 地図データ

地形と国境のベクトル情報は Natural Earth の 1:50m 管理境界データを加工して同梱しています。Natural Earth の地図データはパブリックドメインです: https://www.naturalearthdata.com/
